# ✨ Features Overview — CivicAI

## 🙋‍♂️ Citizen Features
1. **Interactive Conversational AI Assistant**: Guided intake for filing civic complaints in plain language.
2. **Passwordless Authentication**: Quick, secure sign-in via Google One-Tap or Phone/SMS OTP.
3. **GIS Location Pinning**: Automatic landmark recognition and GPS coordinate attachment.
4. **Live Complaint Tracking**: Real-time status progress bar from *Submitted* to *Resolved*.
5. **Multilingual Support**: Built-in support for English, Hindi, and regional languages.

## 🏛️ Administrative Features
1. **Unified Staff Dashboard**: Real-time overview of active, overdue, and resolved grievances.
2. **SLA Breach Monitoring**: Automated countdowns and breach sweep notifications.
3. **Priority & Category Filters**: Instant sorting by Critical/High priority or department.
4. **AI Response Generator**: One-click creation of official progress letters and status responses.
5. **Interactive City Map**: Visual heatmap of complaints by sector and department.

## 🛡️ Security & Reliability Features
1. **Multi-Provider Failover**: Gemini → Bedrock → Claude → Static.
2. **Anti-Bot Honeypot**: Hidden trap fields to catch automated spam.
3. **Rate Limiting & Budget Caps**: Protection against API quota exhaustion.
4. **Timing-Safe Cryptography**: Protection against timing attacks during OTP verification.
