# 🗺️ Product Roadmap — CivicAI

## Phase 1: HackMatrix Core (Current) ✅
- [x] AI-driven complaint classification & priority scoring.
- [x] Passwordless OTP & Google OAuth.
- [x] Citizen helpline chat & interactive GIS map.
- [x] Staff portal with SLA breach sweeper.

## Phase 2: Multi-Channel Expansion (Q3 2026) 🔮
- [ ] **WhatsApp Bot Gateway**: Allow citizens to submit grievances via WhatsApp voice notes or images.
- [ ] **Aadhaar / e-KYC Verification**: Optional official citizen verification.
- [ ] **Automated Duplicate Image Detection**: Computer vision model to detect duplicate photos of the same pothole or garbage dump.

## Phase 3: Smart City Integration (Q4 2026) 🌐
- [ ] **IoT Sensor Feeds**: Direct telemetry integration for water pipeline pressure sensors and smart streetlights.
- [ ] **Predictive Maintenance**: ML models predicting municipal asset failures before complaints occur.
